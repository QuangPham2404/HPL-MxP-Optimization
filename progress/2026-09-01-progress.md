## Root cause (confirmed)

Host `mpirun` (host HPC-X) drove a container MPI app (container HPC-X at
`/opt/hpcx`). Same OpenMPI version (4.1.9a1), different build → the container
ranks' ORTE/PMIx runtime could not complete the cross-node session, so `MPI_Init`
hung. Transport (InfiniBand) was fine. Not an env-pollution issue (ldd confirmed
the app links its own `libmpi.so.40` via RPATH).

## The fix (Approach 1) — resolved

Run the **container's own `mpirun`** and launch the remote `orted` **inside the
container** (consistent MPI end-to-end). Three fixes, all in
`rsh_pbsdsh_container.sh`:

1. bind `/opt/pbs` + `/var/spool/pbs` into the container (pbsdsh works in-container).
2. single-quote the reconstructed `orted` command (it contains `"` and `(`).
3. strip `--daemonize` (otherwise the ephemeral `apptainer exec` unmounts the SIF
   and the backgrounded orted hits a `Bus error`).

**Verification (PASSED):** `probe_approach1_mpi.pbs` (job `55779.gaas`) — all 4

## Second fix discovered this session (NVML library load)

The first Approach-1 HPL attempt (`55799.gaas`, label `2x2_a1`) got past the
cross-node `MPI_Init` (spawn + orted worked) but the app failed:

```
xhpl_mxp: error while loading shared libraries: libnvidia-ml.so.1: cannot open shared object file
```

**Root cause (confirmed via `probe_nvml.pbs`):** `xhpl_mxp` has a direct DT_NEEDED
on `libnvidia-ml.so.1` (driver lib, not in the SIF nor `/usr/local/cuda/lib64`).
`--nv` correctly mounts it at `/.singularity.d/libs/` on *both* nodes, but the
remote `orted`'s reconstructed `LD_LIBRARY_PATH` dropped that path, so remote ranks
could not resolve it (local ranks could). Fix: add `-x PATH -x LD_LIBRARY_PATH` to
the **container** `mpirun`, which re-propagates the full `--nv` library path (incl.
`/.singularity.d/libs`) to every rank. Verified: all 8 ranks resolve
`libnvidia-ml.so.1 => /.singularity.d/libs/libnvidia-ml.so.1`.

(The `libiomp5.so => not found` seen in a bare `ldd` is a red herring: the real
run's `hpl-mxp.sh` sources `hpc-benchmarks-gpu-env.sh`, which adds the `lib/omp`
path.)
